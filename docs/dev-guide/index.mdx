# @primebrick/decimal

`@primebrick/decimal` is a shared Primebrick library providing **exact base-10
decimal arithmetic** on native `bigint`. It is the missing ring between
JavaScript `Number` (binary floating point — `0.1 + 0.2 !== 0.3`) and SQL
`decimal`/`numeric` columns.

Every operation is deterministic and PostgreSQL-faithful: `add(0.1, 0.2)`
returns `0.3`, always. Division follows PostgreSQL's own `select_div_scale`
rule, so `div(1, 3)` yields the same digits as `numeric` division on the
database. Zero dependencies, browser-safe.

```ts
import { dec, add, mul, div, toPG } from "@primebrick/decimal";

const price = dec("19.99");
const total = mul(add(price, "4.50"), 3);   // 73.47
const third = div(1, 3);                    // 0.33333333333333333333 — same digits as PG numeric
```

## When this library is used

Anywhere Primebrick moves money, quantities, or measurements between the
TypeScript layer and PostgreSQL `numeric` columns — the DAL serializes
`Decimal` values through `toPG` so stored values are digit-exact.
